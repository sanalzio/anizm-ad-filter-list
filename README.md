# 🦊 Anizm reklam filtre listesi
Anizm siteleri için bir reklam filtre listesi.

# ✔ Kurulum

## Kısaca
<strong>[`https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt`](https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt)</strong>

## Brave
- Adres çubuğuna `brave://settings/shields/filters` adresini girip ziyaret edin.
- `Özel filtre listesi ekle` başlığının altındaki `"Filtre listesi URL'sini girin
"` kısmına "[`https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt`](https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt)" yazıp ekle tuşuna basın.
- İlk başta gelen `İndirme başarısız oldu` yazısın gördükten sonra `0 saniye önce` yazısı gelene kadar bekleyin.
- İşlem tamamlandı.

## uBlock
- Eklenti simgesine sağ tıklayınca açılan menüden `Seçenekler` ya da `Eklenti Seçenekleri` seçeneğini seçin.
- Açılan sayfada `Filtre listeleri` sayfasına girin.
- Sayfanın en aşağısındaki `İçe aktar` bölümüne tıklayıp açılan bölgeye "[`https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt`](https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt)" yazın.
- Sayfanın en üstündeki `Değişiklikleri kaydet` düğmesine tıklayın.
- İşlem tamamlandı.

## Diğer reklam engelleyiciler
- Diğerleri de işte uBlock veya Brave'de ki gibidir.
- Biraz kurcalayıp reklam engelleyici ayarlarında `Filtre listesi` gibi bir bölme arayın.
- Oradan URL ekleme bölmesi arayın ve "[`https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt`](https://raw.githubusercontent.com/sanalzio/anizm-ad-filter-list/master/anizm-ad-filter-list.txt)" yazıp yakınlarındaki ekle düğmesine basın.
- İşlem muhtemelen tamamlandı.

# + Agresif reklam filtreleri
Reklam ile göz kirliliği elementleri arasında kalan elementleri gizlemek için yazılan ayrı bir filtre listesidir. Diğer listenin yanında kullanılması tavsiye edilir.
